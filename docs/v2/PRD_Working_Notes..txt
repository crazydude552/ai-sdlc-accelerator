1. Product Vision
Product planned to develop is a web tool where user can create a project documentation from the UI and where the project details can be viewed on the screen, and BAs can add requirements of the projects from the ui on selecting the project, and can create respective documents from the details entered such as bsr, fsr etc as per the templates provided. Users can edit the details or requierements, can see the status of the project progress. can create features , pbi and tasks on highlevel, and create test cases and test suites.	
		

2. Business Objectives

This tool will reduce the manual effort and will help to create sdlc documents with a click and can easily integrate with other platforms and tools.

3. User Roles
Admin - must have access to add plugins and all the permissions
BA - access to view all the pages and edit and create new.
Normal- Have read access to all the pages.
